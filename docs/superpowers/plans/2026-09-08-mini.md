# 微信小程序 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for the independent client and SMS tasks; root implements and integrates the server. Do not spawn nested reviewers.

**Goal:** 四项用户需求的本地可运行微信小程序与持久化后端。
**Architecture:** 原生客户端通过REST调用FastAPI后端，PostgreSQL行锁事务执行权限和审批规则，持久outbox发短信。
**Tech Stack:** Python 3.12、FastAPI、psycopg 3、PostgreSQL 16、WXML/WXSS/JS。
**Spec:** docs/spec.md。统一接口：docs/api.md。

## Global Constraints
不修改旧buy-review网页；无真实短信、无发布；仅后端判权限；原生小程序无需npm构建。演示行为必须有明确开关。
