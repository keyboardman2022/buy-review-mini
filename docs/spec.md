# 买前问问 · 微信小程序首版

用户已确认：手机号注册、好友添加、指定好友审批（接受/拒绝且评论必填，发起人选择一票否决/多数等）、好友购物车动态（图片、评论、赞/踩）、审批短信。最新客户端选择为微信小程序；无短信服务，先做接口和本地演示。

原生小程序 WXML/WXSS/JS；独立 Node 24 HTTP 后端；SQLite 持久化；图片存在后端数据目录。与旧网页脚手架分目录保存。仅本地演示，不发布、不发送真实短信。默认监听 127.0.0.1:3210。

登录：短信验证码注册/登录合一，随机验证码5分钟有效、一次使用、5次尝试限制、60秒重发间隔、手机号和IP限流；演示环境可显示验证码以及切换三个虚构演示账号。生产环境禁止演示身份和mock短信。

好友：邀请码/用户编号精确添加，对方接受后成为双向好友；不读取微信好友列表，不公开完整手机号。可拒绝申请、解除好友。购物车仅自己和当前好友可见；私密商品只本人可见（指定审批人可看审批快照）。

商品：标题、价格（整数分）、用途、分类、链接、最多3张图片、好友可见/私密；新增、修改、删除；已有审批保留不可变快照。评论、赞/踩仅可见用户使用，一人一种反应可取消。

审批：选择1～10名当前好友。每位只能提交一次接受/拒绝，评论必填。规则与快照不可变。veto：一拒即拒，全部接受通过；majority：超过指定总人数一半接受通过，已无法获得多数时拒绝，平票拒绝；unanimous：等全员提交后仅全员接受通过。默认72小时到期，未完成到期标记expired，不自动通过。结果由服务器计算，事务中写票和结论；撤回仅本人待审时可用。

短信：验证码、新审批每位审批人、结论发起人；事务outbox去重，发送状态mock/queued/sending/sent/failed/unknown；不将供应商受理等同实际送达。提供腾讯云HTTP适配器（未配资质时不调用）。本地短信中心仅显示当前用户有关记录，不提供验证码记录。暂不做定时催办和冷静期，避免偏离用户最新明确四项范围。

验收：规则边界、鉴权、非好友不可见/不可评论/不可审批、重复投票、多数平票、到期、快照、图片限制、发送去重、手机号验证码流程、持久化。小程序静态检查、页面逻辑契约测试，并尝试微信开发者工具编译验证；未能执行的真机和真实短信明确说明。
